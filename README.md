# Prototype 3


Grid-Based Shooter Prototype

A | D for left/right movement.
Spacebar to Shoot


Enemies will spawn, and will try to touch the no-no zone. Please stop them from trespassing your personal space.

Current Bugs:

When enemies collide with Player, it's due to a paradox in the code where, when enemy spawns at certain square, it occupies space. Because the space is occupied by player already, it keeps them from moving further down.

What went well?

Modifying player movement, fixing player to a specific location, instantiating enemies on the grid and having them move down.

What didn’t go well?

Honestly... I scrapped a memory game so... here we are.

Time... as always.

Just taking more time into research. Putting more love into understanding concepts more.
